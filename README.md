# Simplysm Code

AI 로 개발하는 데 맞춘 Windows 데스크탑 작업대입니다. 폴더를 열어, 파일 탐색기 · 파일 편집 · 터미널을 한 창에서 쓰며 터미널의 코딩 에이전트와 함께 일합니다.

> 이 저장소는 **설치본 배포**와 **문의 접수**를 위한 곳입니다. 소스는 공개하지 않습니다.

## 이런 앱입니다

- **폴더를 그대로 보여 줍니다.** 연 폴더의 파일과 하위 폴더를 있는 그대로 탐색기에 보입니다.
- **파일을 바로 편집합니다.** 고친 내용은 따로 저장하지 않아도 자동으로 저장됩니다.
- **터미널이 들어 있습니다.** 연 폴더에서 바로 셸을 열어 Claude Code 같은 코딩 에이전트를 돌립니다.
- **바깥에서 바뀐 파일이 화면에 반영됩니다.** 터미널의 에이전트가 파일을 고쳐도, 편집기에 열어 둔 파일이 고치기 전 내용으로 남지 않습니다.

## 다운로드

[Releases](../../releases/latest) 에서 `code-win32-x64-<버전>.exe` 를 받아 실행하세요.

- Windows 10/11 (64비트)
- 관리자 권한이 필요 없습니다. 사용자 폴더에 설치됩니다.

## 설치할 때 나오는 파란 경고 (SmartScreen)

이 설치본에는 아직 **코드 서명이 없습니다.** 그래서 처음 실행하면 Windows 가 "PC 보호"라는 파란 창을 띄웁니다.

1. **추가 정보** 를 누릅니다.
2. **실행** 을 누릅니다.

서명은 사용자가 늘어나면 도입할 예정입니다.

## 업데이트

앱이 새 버전을 스스로 내려받아 두고, 준비되면 창 위쪽에 **업데이트 설치** 버튼이 나타납니다. 그 버튼을 누를 때만 재시작하며 적용됩니다. 작업 중에 끼어들지 않습니다.

## 데이터가 있는 곳

- 앱 설정(최근에 연 폴더 기록, 터미널 설정): `%APPDATA%\Simplysm Code`

앱을 지워도 앱 설정은 남습니다. 다시 설치하면 이어서 쓸 수 있습니다. 연 폴더의 파일은 앱이 따로 복사하지 않으므로 앱을 지워도 그대로 있습니다.
